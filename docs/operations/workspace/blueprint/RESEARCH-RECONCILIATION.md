## Explicitly superseded recommendations

The user instructed a complete system before customer acquisition. V2 therefore replaces the historical two-client pilot, third-live-business effort test, paid-cycle contribution gate, buy-versus-custom trial, delayed web/SEO modules and integration-only-after-observed-demand sequence. Full scope is qualified through synthetic service journeys, noncustomer usability exercises and actual agency provider readiness. Business outcomes remain unknown before customers and are measured after launch.

The 45 inherited V2/V3 tests and 33 V1 tests remain archived exactly inside each acceptance record. Active V2 expectations override old phase ordering. AD22 now covers supported Google reads/writes; AD25 validates economic calculations without requiring paid cycles; AD30 requires complete-before-acquisition; AD33 scopes lost-authority-tail recovery to proven affected boundaries. AD15 no longer blocks all routine operation solely because a feedback batch was unanswered. F22 measures effort without silently deferring promised functionality. All 36 new V2 tests are proposed, not executed results.

There is no claim that all work must become autonomous. Professional ad judgment, contract decisions and deliberate publishing remain named human steps. A promised automated operation must have its working adapter and verified result. Human execution is explicitly visible in the workflow and runbook rather than hidden status-changing theater.

## Conflicts resolved

1. **Care onboarding:** current catalog has newer $195/$395 fields and older $375/$650 text. V2 chooses the newer schedule for new quotes, preserves its waivers and saved agreements, and requires reconciliation of all consumers. This is a planned source correction, not a change already deployed.
2. **Measurement overlap:** four website builds and applicable first monthly production cycles already include supported basic measurement. Reuse it; quote only truly incremental ads/advanced measurement. Do not silently add the full $795 module.
3. **Existing commerce:** Storefront Launch and Commerce Care are current offers. They keep functional project/Care delivery. The new ads offer excludes Shopping/feeds/other new ecommerce advertising; that exclusion does not delete existing commerce services.
4. **Historical competitor ownership:** V1 strategy and pricing review disagree about Footbridge account ownership. V2 makes no competitor-ownership accusation. W&M's client-ownership policy stands independently.
5. **Google documentation summary:** the current official migration/access page bodies describe project-based access after September 2026 while their auto-summary still refers to tokens. V2 follows the body and requires a fresh implementation check.
6. **Restore breadth:** current intact identity is not rolled back to reconstruct reports/files. Lost authority history requires fresh independent verification for affected scope; global or unknown scope can require broader recovery. An old receipt prefix never proves no missing revocation.
