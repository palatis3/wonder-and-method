EXAMPLE (MADE UP)
A Mount Vernon provider uses one registration form for public course attendees and organizations asking about private training.
Write the next step for each audience. Public sessions need dates, format, prerequisites and confirmation rules. Private groups need an organizer brief covering the intended outcome, size and course format before participant details. If a Gambier organization proposes a date, label it as a preference until the instructor and scope are agreed. Plan what replaces a public session link when the date passes.
