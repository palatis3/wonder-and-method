EXAMPLE (MADE UP)
Fictional example: a Biddeford studio tests a three-step project inquiry. A customer returns to the first step to change the service type, which makes one later answer irrelevant. The form flags the affected question for review instead of preserving the old answer silently or discarding every unrelated detail the customer already entered.
Draft an ordinary inquiry, then change a controlling answer midway through. Test the previous button, browser back and return from a help link. Record which answers remain valid and what the customer must review.
